## 0.1.0

* Initial package layout for Solana Actions and Blinks: a public barrel, pure-Dart core, wallet adapters, and Flutter widgets.
* Depends on `http`, the `solana_kit` modules this package actually calls, and `solana_mobile_client` for Android Mobile Wallet Adapter.
* Requires Dart 3.13 because `solana_kit_rpc` 0.11.0 does.
